# Инструкция по пушу в GitHub

Репозиторий: https://github.com/Evoyya/ArtNail-recommender-system (remote `origin`)

## Ветки

| Ветка | Назначение | Правила |
|---|---|---|
| `main` | основная ветка | не трогаем без необходимости |
| `product` | продуктовая версия (бот) | не трогаем |
| `backup/recommender-v1` | **бэкап** рекомендательной системы до рефакторинга (коммит `63cfab7`) | только чтение, не коммитить и не пушить в неё |
| `dev/recommender-refactor` | **рабочая ветка** для доработки рекомендательной системы | все правки — сюда |

## Ежедневный цикл

```bash
git checkout dev/recommender-refactor     # убедиться, что мы в рабочей ветке
git status                                # посмотреть, что изменилось
git add <файлы>                           # добавлять явно, не "git add ."
git diff --staged --stat                  # проверить, ЧТО именно уйдёт в коммит
git commit -m "Краткое описание изменения"
git push -u origin dev/recommender-refactor   # первый раз; дальше просто: git push
```

## Чек-лист перед каждым пушем

1. Ветка — `dev/recommender-refactor` (`git branch --show-current`).
2. В `git diff --staged --stat` нет данных (`*.csv`, `*.xlsx`, `*.pkl`, `*.parquet`, `results/`), `.env` и ключей.
3. В коммите нет файлов Claude / ИИ-ассистента (см. раздел ниже).
4. Ноутбуки: перед коммитом желательно очистить тяжёлые выводы ячеек.

## ⚠️ Данные и инструкции Claude НЕ должны попадать на GitHub

Не пушим:

- папку `.claude/` (настройки, права, локальные конфиги, память сессий);
- `CLAUDE.md`, `CLAUDE.local.md` (инструкции для Claude);
- папку `refactoring/` (аудиты и заметки, сгенерированные Claude);
- любые дампы переписки, промпты, логи сессий;
- `.env`, токены, ключи (в т.ч. токен `gh`).

Эти пути добавлены в `.gitignore`:

```gitignore
.claude/
CLAUDE.md
CLAUDE.local.md
refactoring/
```

Важно:

- `.gitignore` защищает только **неотслеживаемые** файлы. Если файл уже попал в индекс, уберите его из git, сохранив на диске:
  ```bash
  git rm --cached -r refactoring/
  ```
- Проверка, что ничего лишнего не отслеживается (вывод должен быть пустым):
  ```bash
  git ls-files | grep -iE 'claude|refactoring|\.env'
  ```
- Проверка, что путь игнорируется:
  ```bash
  git check-ignore -v refactoring/01_ml_audit.md
  ```
- Если Claude создаёт коммит, не добавляйте в сообщение или файлы ничего, что раскрывает содержимое его инструкций или данных сессии.
- Если секрет или файл Claude уже запушен: удаления коммитом недостаточно — он остаётся в истории. Нужно переписать историю (`git filter-repo`) и force-push, а токены — отозвать и перевыпустить.

## Слияние результата

Когда доработка готова: создайте Pull Request `dev/recommender-refactor` → `main` на GitHub, проверьте вкладку *Files changed* на отсутствие лишних файлов и только потом мержите.

## Если что-то пошло не так

Вернуться к бэкапу рекомендательной системы:

```bash
git checkout backup/recommender-v1
git checkout -b dev/recommender-refactor-2   # новая рабочая ветка от бэкапа
```
